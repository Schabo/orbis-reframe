# Security

orbis-reframe opens video files and project files that may come from
anyone, so a file that crashes the app or makes it do something it
shouldn't is a security problem.

## Reporting a problem

Please report it privately with GitHub's
[private vulnerability reporting](https://github.com/Schabo/orbis-reframe/security/advisories/new)
rather than in a public issue. Describe what happens, and attach or link
the file that triggers it if you can.

orbis-reframe is run by one person in their spare time, so there's no
guaranteed response time, but reports are taken seriously and you'll get an
answer.

## Supported versions

Fixes go into the next release. Only the latest release is supported.
