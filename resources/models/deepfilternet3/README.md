# DeepFilterNet 3 (ONNX)

The speech-enhancement model behind the "Voice only" and "Voice + ambience"
noise modes (`src/insv/VoiceIsolator`).

  unpacked unchanged: `enc.onnx`, `erb_dec.onnx`, `df_dec.onnx`,
  `config.ini`.
